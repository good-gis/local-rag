# Help Command

Отвечай на вопросы о проекте Local RAG, используя контекст из CLAUDE.md и исходного кода.

## Инструкции

1. Сначала прочитай CLAUDE.md чтобы понять контекст проекта
2. При вопросах о коде используй Glob/Grep для поиска релевантных файлов
3. Отвечай кратко и с примерами кода где уместно
4. Используй русский язык для ответов

## Области знаний

- **Структура проекта**: где находятся компоненты, сервисы, роуты
- **Команды**: как запустить, собрать, протестировать
- **Код-стайл**: правила оформления кода в проекте
- **Angular паттерны**: signals, standalone components, control flow

## Примеры вопросов

- "Как создать новый компонент?"
- "Где находится конфигурация роутинга?"
- "Какой код-стайл используется?"
